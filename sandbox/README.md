# Sandbox de execução

Execução isolada do código enviado pelos estudantes, sem acesso ao sistema de arquivos do servidor, à rede externa ou a outros processos, com limite de tempo, memória e CPU (RNF01, RNF02 e RNF03).

Tarefas relacionadas: T1.6 (prova de conceito) e T2.1 (execução das submissões reais).
