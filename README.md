# Aplicativo gamificado para o ensino de lógica de programação

Aplicativo que apoia estudantes iniciantes em programação por meio de gamificação: o estudante lê um conceito, resolve exercícios com correção automática, ganha XP, sobe de nível e desbloqueia as próximas missões da trilha.

Projeto da disciplina **Construção de Aplicações Utilizando Frameworks** — Tecnologia em Análise e Desenvolvimento de Sistemas, IFPR Campus Londrina.

**Equipe:** Fernanda Yumi Tomoi e Victória Camile Campos Bertuchi

## Estrutura do repositório

```
.
├── backend/              API, autenticação e correção automática
├── frontend/             Telas, editor de código e dashboard
├── sandbox/              Execução isolada do código dos estudantes
├── database/
│   ├── migrations/       Evolução do esquema do banco
│   └── seeds/            Dados iniciais (trilhas e exercícios)
├── docs/                 Requisitos, modelagem e planejamento
├── CONTRIBUTING.md       Fluxo de branches, commits e pull requests
└── README.md
```
